Questions

What file formats can I upload?

Excel (.xlsx, .xls), CSV, TSV and plain text (.txt) files up to 20 MB. Commas, semicolons, tabs and pipes are detected automatically. For Excel, the first sheet is used.

Does my data get stored?

Your file is processed on the server and the finished reports are kept in memory for up to an hour so you can preview and download them. After that they are deleted. Nothing is shared with anyone.

How many rows can it handle?

Reports include up to 50,000 rows. If your file has more, the report says how many rows were included.

My dates or numbers are not detected. Why?

A column is treated as a number or date when at least 95% of its filled cells match. Mixed values (for example "N/A" in a number column) can prevent that. Columns named like "ID", "Phone" or "Code" are kept as text on purpose.

Do the reports work offline?

Tables and filters do. The charts use a small charting library that loads from the internet, so charts need a connection the first time a report is opened.
